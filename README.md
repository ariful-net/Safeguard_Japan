# SafeGuard Japan & Emergency Relief Portal 🛡️🚨

An integrated All-in-One Emergency Response & Disaster Relief System built for Japan.
Provides real-time JMA disaster alerts, GPS-based Evacuation Shelter locating, multilingual safety status signaling, and P2P relief request coordination.

## Tech Stack
- **Frontend:** HTML5, Tailwind CSS, JavaScript (ES6+), Leaflet.js (Map), Chart.js
- **Backend:** Java 17, Spring Boot, REST API
- **Storage:** LocalStorage (Offline Mode) & MySQL/PostgreSQL
